# 协作开发指南（同事电脑上手步骤）

> 前提：两人共用同一个 Claude 账号 与 同一个 GitHub 账号（syu-source）。
> 项目为纯静态站（HTML/CSS/JS），无需 Node/构建环境；只需 git、GitHub CLI、Claude Code、Python 3（macOS 自带，交接技能用到）。

## 一、首次配置（只做一次）

### 1. 安装并登录 GitHub CLI

```bash
brew install gh
```

```bash
gh auth login
```

- 选 GitHub.com → HTTPS → Login with a web browser，用 **syu-source** 账号完成浏览器授权（账号凭据由本人输入）。

### 2. 克隆仓库

```bash
git clone https://github.com/syu-source/zenkai-ai-site.git
```

（文件夹名可自行改，例如 `AI consultant service`。）

### 3. 设置本机提交者身份（重要）

共用 GitHub 账号的情况下，靠这个区分「是谁提交的」。在仓库文件夹内执行，名字写自己的真名：

```bash
git config user.name "你的名字"
```

```bash
git config user.email "你的邮箱"
```

### 4. 安装 Claude Code 并登录

- 桌面版 / VSCode 扩展 / CLI 均可，登录**同一个 Claude 账号**。
- 用 Claude Code 打开仓库文件夹即可：项目规则（CLAUDE.md）、计划（PROJECT_PLAN.md）、进度（worklog.md）和 `/handover` `/start` 两个技能都在仓库里，克隆下来就自动生效，无需额外配置。

## 二、日常工作流（每次都遵守）

1. **开工**：先 `git pull --rebase` 拉最新代码，然后在 Claude Code 里发 `/start` —— 会自动读取 `handover/` 里最新的交接书，恢复上一个人的工作上下文。
2. **干活**：遵守 CLAUDE.md 铁则（与 Claude 对话用中文、网站内容全日文、全站禁 emoji、禁改 design-system.css、不捏造实绩等）。
3. **收工**：发 `/handover` 生成交接书 → 把代码改动＋交接书＋worklog 记录一起 commit → `git push`。**不 push 等于没做**——对方看不到。

## 三、注意事项

- **两人尽量不要同时改同一个文件**。改动前在微信等渠道打个招呼；worklog.md 若冲突，合并时保留双方条目。
- **共用 Claude 账号意味着共享用量限额**：两人同时重度使用会互相挤占额度，大任务错峰进行。
- Claude 的会话历史和个人记忆**不跨电脑同步**，项目知识以仓库内文件（CLAUDE.md / PROJECT_PLAN.md / worklog.md / handover/）为准——所以收工必写交接书。
- 临时预览链接：https://syu-source.github.io/zenkai-ai-site/ （有密码门；**密码口头传达，不写在仓库里**——本仓库是公开的）。
- 密码门只在 github.io 域名生效，本地双击 HTML 预览不受影响。
