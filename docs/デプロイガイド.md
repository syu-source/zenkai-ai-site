# 网站上线部署指南（非工程师版）

> 本指南面向不熟悉技术操作的经营者，说明如何把本项目（纯静态HTML网站）发布到互联网上。全程无需编程知识，跟着步骤操作即可。
> 编写时间：2026年7月（价格、方案信息已于编写当日核实，实际以各服务商官网为准，正式签约前请再确认一次）。

---

## 一、这是一个什么样的网站

本项目是**纯静态网站**（HTML+CSS+JS，没有数据库、没有后台程序）。这意味着：

- 不需要买"云服务器"这种复杂产品，只需要一个**静态网站托管**服务即可。
- 表单（咨询、资料下载申请）用 **Googleフォーム**（Google表单）承接，日程预约用 **TimeRex** 嵌入，都是第三方免费/低价工具，不需要自建后台。
- 部署方式基本上是"把整个文件夹上传到托管服务商"，操作类似于把文件拖进网盘。

## 二、推荐托管方案对比

| 方案 | 费用（2026年7月核实） | 难易度 | 界面语言 | 特点 |
|---|---|---|---|---|
| **Cloudflare Pages** | **免费**（静态网站托管完全免费、流量无上限；仅当用到服务器端Functions功能时才可能产生费用，本项目用不到） | 中等（需要注册Cloudflare账号，通过网页上传文件或连接GitHub） | 英文为主（后台部分有中文/日文，核心操作页面是英文） | 全球CDN加速快、免费额度对企业官网完全够用、最省钱 |
| **さくらのレンタルサーバ**（樱花虚拟主机） | スタンダードプラン 月额约 **660円**（月付）／约 **500円/月**（三年一次性付款换算） | 简单（日本本土服务，日文界面，FTP/文件管理器上传即可） | 全日文 | 日本本土老牌服务商，中小企业常用，客服支持日文，适合完全不懂技术、希望"打电话有人接"的情况 |
| **Xserver**（エックスサーバー） | スタンダードプラン 月额约 **495円起**（36个月合约换算，常有优惠活动含免费域名） | 简单（日本市占率最高的虚拟主机，日文界面） | 全日文 | 日本个人/中小企业网站首选品牌，速度稳定，域名+主机可一站式购买 | 

**建议**：
- 如果不介意英文操作界面、想要**完全免费**且不需要日文客服支持 → 选 **Cloudflare Pages**。
- 如果希望**全日文操作、有本土客服**、每月几百日元也能接受 → 选 **さくらのレンタルサーバ** 或 **Xserver**（二者体验接近，Xserver知名度更高、域名优惠活动更常见）。
- 三个方案都能满足本项目（纯静态网站）的需求，选择主要看"想不想花钱换日文客服的安心感"。

## 四、上线操作步骤

### 步骤1：注册并配置 Googleフォーム（表单）

本网站中，以下功能依赖 Googleフォーム：
- `download.html`（资料下载申请）
- `contact.html`（问い合わせフォーム）
- `lp/index.html`（LP页无料AI诊断申込表单）

操作方法（简要）：
1. 使用公司的Google账号，访问 forms.google.com，点击"新建空白表单"。
2. 按 PROJECT_PLAN.md 中约定的字段设置问题：会社名／氏名／メール／業種（選択式）／相談内容（選択＋自由記述）／電話（任意）。建议每个用途（资料下载／问合わせ／LP诊断）分别建一个独立表单，方便统计。
3. 在表单编辑页右上角点击"发送"（送信）图标，选择"嵌入HTML"（`<>`）标签，复制里面的 `<iframe>` 代码。
4. 把复制到的 `iframe` 代码，替换掉网站文件中标记为 **【要差し替え：GoogleフォームembedURL】** 的位置（在 `contact.html` 中）。
5. 如果只需要一个"跳转链接"而不是嵌入，则在表单"发送"弹窗中选择"链接"图标，复制URL，替换 **【要差し替え：GoogleフォームURL】**（在 `download.html` 和 `lp/index.html` 中）。
6. 在表单的"回答"（回答）标签页，点击右上角的Sheets图标，可以让所有提交自动汇总进一个Google表格，方便销售跟进。

### 步骤2：注册并配置 TimeRex（日程预约）

1. 访问 timerex.net，使用公司邮箱注册账号（有免费的「フリー」方案，无需信用卡）。
2. 连接公司使用的日历工具（Google日历等），设置可预约的时间段（建议对齐营业时间 9:00〜18:00、水曜定休）。
3. 在TimeRex后台的"埋め込み"（嵌入）设置中，生成嵌入代码。
4. 把嵌入代码替换 `contact.html` 中标记为 **【要差し替え：TimeRex埋め込みURL】** 的位置。

### 步骤3：占位符（要差し替え）替换清单

网站中所有需要老板/运营方手动填写真实信息的地方，都用**【要差し替え：说明】**的形式标出。上线前请逐一替换（本清单为编写本指南时，站内已存在页面中检索到的占位符，其余页面完成后请再执行一次全站检索确认无遗漏）：

| 占位符 | 出现位置（当前已知） | 需要填写的内容 |
|---|---|---|
| 【要差し替え：代表者氏名】 | company.html | 正式对外公开的代表者姓名 |
| 【要差し替え：代表者写真】 | company.html | 代表者证件照/形象照（建议正装、明亮背景） |
| 【要差し替え：電話番号】 | company.html | 对外公开的联系电话（座机或代表号） |
| 【要差し替え：地図埋め込み】 | company.html | Googleマップ嵌入代码（Google地图分享→嵌入地图→复制iframe代码） |
| 【要差し替え：GoogleフォームURL】 | download.html、lp/index.html | 资料下载申请表单 / LP诊断申込表单的Google表单链接 |
| 【要差し替え：GoogleフォームembedURL】 | contact.html | 问い合わせ表单的Google表单嵌入iframe代码 |
| 【要差し替え：TimeRex埋め込みURL】 | contact.html | TimeRex预约页面嵌入代码 |
| 【要差し替え：AI事業用メールアドレス】 | contact.html | AI咨询事业专用对外邮箱地址 |

> 提醒：`index.html`（首页）、`services/`（各服务详情页）、`industries/`（行业页）、`cases.html`、`pricing.html` 等页面由并行任务制作，可能包含各自的占位符（如OGP图片、实绩数据等）。**正式上线前，建议对全站文件执行一次关键词搜索**（在文件夹中搜索"要差し替え"），确保没有遗漏任何占位符。

### 步骤4：上传网站文件

- **Cloudflare Pages**：登录Cloudflare账号 → Workers & Pages → 创建应用 → 选择"直接上传"（Upload assets），把整个项目文件夹（不含 `docs/`、`research/`、`.git/` 等非网站文件）拖入上传即可，几分钟内自动生成一个临时网址，绑定正式域名后即可对外使用。
- **さくらのレンタルサーバ / Xserver**：登录管理后台，找到"文件管理器"（ファイルマネージャー）或使用FTP软件（如FileZilla），把项目文件夹内容上传到网站根目录（通常是 `public_html` 或类似名称的文件夹）。

### 步骤5：绑定域名

在域名注册商处购买域名后，按照所选托管服务商的说明文档，把域名的DNS解析指向该托管服务商（Cloudflare Pages / さくらのレンタルサーバ / Xserver 均提供图文教程，操作时按照对应服务商当时的最新说明进行，此处不逐一列出以免版本过时）。
